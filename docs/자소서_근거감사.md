1. **학원에서 실제로 겪은 일** — 학생 질문을 받으면서 반복해서 느낀 것이 있으십니까? 구체적 사례가 하나라도 있으면 좋습니다. 없으면 이 절을 업무 사실 위주로 줄이겠습니다.
2. **KIST에서 하루가 실제로 어땠는지** — 조정에 시간을 많이 썼습니까, 아니면 다른 비중이었습니까?
3. **AWS 이틀 동안 실제로 막혔던 것** — API 연동에서 문제를 겪으셨습니까?
4. **(나) 항목을 남겨도 되는지** — 해석과 각오는 자소서에서 지원자가 직접 쓰는 부분이라 창작이 허용됩니다. 다만 주인님 생각과 다르면 바꿔야 합니다.

답을 주시면 (가)는 사실로 교체하고, 못 채우는 부분은 **삭제**하겠습니다. 시간이 없으시면 "삭제"라고만 하셔도 됩니다. 분량은 충분히 남습니다.
